AI-powered Unified DevOps and Cloud Engineering Platform.

Design. Build. Deploy. Monitor. Troubleshoot.

## Technology Stack

- Java 21
- Spring Boot
- React + TypeScript
- PostgreSQL
- RabbitMQ
- Docker
- Terraform / OpenTofu
- AWS

## Project Structure

- frontend: React application
- backend: Spring Boot API
- workers: Background execution workers
- infrastructure: Docker and cloud infrastructure
- docs: Architecture and technical documentation
